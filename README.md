📋 Task Manager App

A simple task management app built using .NET MAUI 💻📱
تطبيق لإدارة المهام تم تطويره باستخدام ‎.NET MAUI.

🧠 App Idea | فكرة التطبيق

A simple application that helps users organize their daily tasks efficiently.
تطبيق بسيط يساعد المستخدم على تنظيم مهامه اليومية بسهولة.

⚙️ Features | المميزات
Add new tasks | إضافة مهام جديدة
View task list | عرض قائمة المهام
Delete tasks | حذف المهام
Simple and clean UI | واجهة بسيطة وسهلة الاستخدام
🕹️ Usage | طريقة الاستخدام
Enter a task in the input field | اكتب المهمة في الحقل
Click "Add Task" to add it | اضغط "Add Task" للإضافة
Click "Delete" to remove a task | اضغط "Delete" لحذف المهمة
🎯 Objective | الهدف

Improve productivity by organizing and tracking daily tasks.
تحسين الإنتاجية من خلال تنظيم وتتبع المهام اليومية.
